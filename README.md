# Painel Econômico

Painel web com os principais indicadores econômicos do Brasil, com foco em
macroeconomia: taxa de juros, câmbio, PIB (ótica da demanda e da oferta),
investimento, consumo, crédito, endividamento, desemprego, população
economicamente ativa, gasto público e orçamento público.
